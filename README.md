# Söeportree toonikaart

Tööriist söeportree joonistamiseks foto järgi. Jagab foto teravate piiridega toonialadeks, et näeksid, kuhu tuleb tumedaim süsi ja kuhu jääb paber.

Ava: https://robitaul.github.io/toonikaart/

- Vali foto ja kärbi see näole.
- Vali toonide arv ja kiirvalik.
- Joonistamisrežiimis saad toone samm-sammult vaadata, ekraan püsib ärkvel.
- Pilt ja seaded jäävad ainult sinu seadmesse.
